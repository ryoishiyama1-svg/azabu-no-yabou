# 麻布の野望

名門高校を城に見立てた国盗りシミュレーション（iPhone対応のWebアプリ / PWA）。
地図上の学校をすべて制覇すれば天下統一です。版は5つ：東京版（都心・二十三区・東京・首都圏）、全国版、関西版、東海版、九州版。

※実在の学校名を使ったフィクションです。兵力などの能力値はすべて架空で、実際の学校とは関係ありません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面と見た目 |
| `js/data.js` | 勢力・学校（城）のデータ |
| `js/game.js` | 地図の作成、ルール、合戦、敵の思考 |
| `js/ui.js` | 画面の表示と操作 |
| `manifest.json` / `sw.js` | ホーム画面への追加・オフライン対応 |
| `tools/make-icons.ps1` | アイコン画像を作り直すスクリプト |

## 調整したいとき

- 学校を増やす：`js/data.js` の `SCHOOL_ROWS` に1行追加（緯度・経度を入れると地図と道が自動で作られます。9列目が版）
- 版を増やす：`js/data.js` の `EDITIONS` と `SCENARIOS` に足す（地図の縮尺 `lin`、海・陸・川・地名の `scenery`）
- 難しさ：`js/game.js` の `RULES`
- 公開後にファイルを更新したら、`sw.js` の `VERSION` を上げる
